## What is trainer-only (🎤)

Everything marked 🎤 exists **only in this repo**: trainer notes, trainer answers, exam answers, exercise
solutions (cells starting with `# SOLUTION`). The trainee repo is generated by `../tools/build_trainee_version.py`.

Each notebook has:
- an intro + **🎤 Trainer notes** (key message, questions to ask, common mistakes, exam link)
- 🎤 context quotes next to the harder sections
- **✅ Check yourself** questions + 🎤 answers
- **📝 Exam-style practice** (3 multiple-choice questions, original, not exam dumps) + 🎤 answers

## Run sheet

1. Before the session: run every notebook once in a **Free Edition** account (not a trial: trainees have Free Edition).
2. Per topic: show the Academy demo video → run the notebook live → trainees repeat → Check yourself → exam questions.
3. One trainee "drives" (shares screen) per notebook; the others follow in their own workspace.
4. End of each notebook: trainees **commit & push** to their own GitHub repo.
